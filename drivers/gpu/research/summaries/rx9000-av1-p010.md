# VCN5 AV1 P010 precision proof

Pinned primary Mesa 26.2.4 `src/amd/common/ac_vcn_dec.c` supplies unchanged
`build_av1_msg`, `vcn_build_decode_cmd`, `ac_vcn_dec_calc_ctx_size_av1`,
`ac_vcn_dec_frame_ctx_size_av1`, `ac_vcn_av1_init_probs`, tier3 reference
construction and packet helpers in `ac_vcn.c`. `ac_video_dec.h` supplies
actual input structures; `ac_vcn_dec.h` supplies firmware message structures.
The host extractor preserves these executed functions and assignments.

In `build_av1_msg`, input bit depth 10 sets both minus8 fields to 2. A P010
surface selects p010_mode and msb_mode rather than NV12 random dithering.
Generic decode assignments use the actual plane pitches and UV address.
The separate P010 fixture therefore keeps the ten sample bits, rather than
using a plausible 8-bit result as acceptance. Exact original luma/chroma
samples have nonzero low two bits, and a dedicated native-model fault drops
those bits while preserving upper bytes. Full byte comparisons reject it.

Actual GFX12 Addrlib and `radeon_surf` construction for both external revisions
(0x40 and 0x50) produce 256/128 sample pitches, UV 65,536 and total 98,304 at
256×128/10-bit. The context/CDF sizing is depth-independent for this version;
no guessed depth multiplier or reduced hardware context is used. The sparse
test model omits only opaque zero context tail storage while counting every
initialization write and claiming the full physical pool interval.

Independent libaom 3.13.1 generation and FFmpeg 8.0 CBS/decode validate the
lossless reduced-still fixture and exact sample precision. See
`../../fixtures/av1/README-10.md` for pinned provenance, hashes and commands.
This is a bounded proof prerequisite; it does not prove arbitrary application
streams or justify advertising the entire AV1 profile/range capability row.
