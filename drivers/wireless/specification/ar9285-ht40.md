# AR9285 N85H3 full20/40 and SGI40 qualification

This is a software contract for externally supplied board measurements.
No measurement, signed asset or physical acceptance is supplied. The
source-complete continuation and six new native cases are pending release
and native validation. Existing N85H/B/T/Q v1/v2 remain unchanged and20-only.

The admitted source is AR9285 revision2, one RX/TX chain, a fully checked
376-byte `eeprom_4k` image and both HT20/HT40 negative capability flags clear.
The primary and secondary are both1–13 and differ by4 channel numbers.
Primary/control is2407+5*primary MHz; extension is primary±20MHz; synth is
primary±10MHz. The whole occupied span is synth±20MHz. Channel14, SGI20,
TX STBC, LDPC, tracking and other chips are not inferred.

`ht40_qualification_request(secondary)` hashes the actual current nominal20
H1/2 identity and complete payload, image, INI gain selection, primary and
extension geometry, ten planned registers and PDADC compensation, and the
exact full20/40 native reset/calibration/packet/response/fallback algorithm.
The filename is `ath9k/ar9285-ht40-v3-ch<P>-above-<MAC>.bin` or
`...-below-<MAC>.bin`; P is decimal, MAC twelve lowercase hex digits.
A file from another primary, extension, factory image, current20 receipt,
source recipe or power program is foreign. The wide qualifier is checked
before40 calibration, and its expected receipt is checked against the
separate actual fresh40 report before packet allocation/publication.

All fields are little endian. H3 has384 bytes and a256-byte header:

| Offset | Field |
| ---: | --- |
|0| `N85H`, version:u16=3, header:u16=256 |
|8| length:u32=384 |
|12| vendor:u16=0x168c/device:u16=0x002b |
|16| request SHA-256[32] |
|48| MAC[6] |
|54| primary:u8, width:u8=40, secondary:u8, direction:u8 (1 above,3 below) |
|58| measured antenna upper bound:i16 half-dBm, at least the base bound |
|60| board ceiling:i16 half-dBm |
|62| nonzero TX MCS0–7 subset:u8, within the current H1/2 selection |
|63| GI flags:u8: bit0 TX SGI40, bit1 RX SGI40; no other bits |
|64| expected actual fresh40 calibration SHA-256[32], nonzero |
|96| complete current H1/2 signed-body SHA-256[32] |
|128| reserved[128]=0 |
|256| 64 conducted-peak:i16 half-dBm entries |

The actual receipt hash includes primary/secondary/direction, country,
primary frequency, fixed nominal host budget, actual PA/IQ, both measured
and sanitized NF planes, final ADC gain/DC register, PDADC increment and
all ten installed power registers. It is an expected result from the signer,
never an invented controller receipt. A different actual result forces real20
fallback or terminal ownership. The static program retains its exact budget
when host policy is relaxed; a tighter full-span rule cannot silently rewrite
power under the old qualification.

The peak slots are:

| Slots | Required measured operation |
| --- | --- |
|0| maximum over the complete admitted program and static environment |
|1–3| actual20 calibration, actual40 calibration, reset/transition |
|4–7| legacy/control20, legacy/control40, automatic response20, automatic response40 |
|8–19| twelve legacy rates in the20 program |
|20–31| twelve legacy rates in the40 program |
|32–39| HT20 long-GI MCS0–7 |
|40–47| HT40 long-GI MCS0–7 |
|48–55| HT40 short-GI TX MCS0–7; all zero when TX SGI40 is disabled |
|56–58| reserved zero; separate B/T/Q3 qualification is required |
|59–63| admitted RX-STBC response, cancel/stop transient, real20 association fallback, policy closure, full static board envelope |

Every active slot is known and in−512..256; slot0 bounds every other active
slot. Missing values, overflow markers, reserved data and unsupported modes
are refused. Slot0 plus the measured antenna bound must fit the H3 ceiling,
the preceding H1/2 ceiling and every current host rule overlapping the entire
40MHz span. Current country and permission must still cover the exact
calibrated program. The record covers the full fixed temperature, supply,
antenna, Bluetooth and posture envelope; runtime tracking is not implied.
RX SGI40 does not grant TX SGI40. SGI20 is never admitted.

The primary CCK/OFDM/HT20 targets and CTLs use the control channel, extension
CCK/OFDM targets/CTLs use the extension, HT40 target/CTL and detector
interpolation use the RF center. EEPROM HT40 compensation (modal byte30,
absolute82; minor<2 uses2) is added only to HT40 rate7/8, not duplicate or
extension powers. Native six-bit overflow is refused. The source40 INI,
modal settling, wide spur/subchannel/phase, turbo and extension CCA precede
actual wide carrier-leakage/PA/both-NF/ADC-gain/DC/IQ calibration. No20
receipt is reused as the40 hardware proof.

B/T/Q3 have the existing96-byte record structure and distinct v3 request
prefixes/filenames: `ar9285-{rxba,txba,qos}-v3-ch<P>-ext<S>-<MAC>.bin`.
Their version is3 and bytes54–57 are the H3 geometry tuple above. Remaining
window/TID/peak/ceiling/reserved fields retain their own program meanings.
Each request binds the complete H3 body digest and the new width/GI native
algorithm; every invocation intersects the full40 span and nests the H3 and
preceding source capabilities. Old B/T/Q records cannot enable their programs
on a40 owner.

A peer response that selects20 is detected before M2/key/BA/DATA publication.
The driver withdraws the40 generation, proves native DMA stopped, cold-resets
and actually calibrates20, rediscovers the BSS and makes one forced20 join.
Missing/failed qualification or unexpected actual40 receipt never supplies a
40 packet owner. A failed DMA proof/source/policy leaves the owner terminal.
Ordinary recovery/resume also start actual20 at the retained primary. Netdev
names, keys, BA and capture tokens are replaced; association preservation and
40-width restoration after an off-channel scan are not claimed.

The source references are Linux7.2 `ar5008_phy.c` (INI/channel/delta slope),
`ar9002_phy.c` (center synth, wide spur, extension NF), `eeprom_4k.c` (target,
CTL, detector and increment), `ar9002_calib.c`/`calib.c` (wide CLC/NF/ADC/IQ),
`hw.c` (centers/joined CCA) and `xmit.c`/`mac.h`/`mac.c` (native duration,
TX/RX width/GI). Exact hashes are saved with the implementation evidence.
