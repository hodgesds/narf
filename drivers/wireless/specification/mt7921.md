# narf-drivers-mt7921 — Specification (stub)

> Status: **PCI ID-match table only.** No driver code beyond the
> vendor/device match. No CONNAC2 register sketch is retained in
> this tree because no public MediaTek datasheet covers the MT7921
> register map and we will not derive one from third-party sources.

## Scope

- **Match:** PCI vendor `0x14C3` / device `0x7961`.
- **Probe action:** record the binding via
  `narf_drivers::record_bound` so the bus dispatcher can see the
  device.

That is the entire current scope. Bring-up of the radio is **out of
scope** until MediaTek publishes a register reference or releases a
permissively-licensed driver.

## Clean-room provenance

- **No GPL `mt76` source consulted.**
- **No leaked or NDA datasheet consulted.**
- The vendor/device ID pair is the only material consumed and is
  visible from PCI enumeration of any MT7921-bearing host.
