# Communication

## Contributing

Anyone can contribute to NARF, from any background. Contributions are judged on the work itself.

## How we talk to each other

This is not a code of conduct. It is a short statement of how communication in this project works:

- Be respectful in communication.
- No personal attacks. Disagree with the work, the design, or the decision — not the person.
- Assume good faith. If a message reads as hostile, ask what was meant before escalating.

## Changing the communication style

The way this project communicates is set by the people who built it and keep it running. Proposing changes to the communication style is not appropriate unless you are a major technical contributor to the project.

## Enforcement

Violators of these communication guidelines may be banned from the project.
